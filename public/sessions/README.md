# Voib Sessions

Ten original, computer-synthesized instrumental studies by Voib Studio, bundled for direct playback in this portfolio application. No commercial recording, sampled performance, or YouTube audio is used.

Neon Drift, Afterglow and Quiet Orbit restore the original 24-second demo studies. The seven new arrangements are 72-second pieces generated by `scripts/generate-sessions.py`. Artwork is original vector composition. These are instrumental studies, not recordings by the artists in the separate official YouTube catalogue.

These original audio files and covers may be used, shared and modified with the Voib project, including its public portfolio deployment.
